# Ahmadul Karim Chowdhury | Personal Website

Live site: https://akc23.github.io

One page portfolio of a data analyst, data engineer and visualization expert. It covers experience, selected projects, research, certifications and client reviews.

## Built with

Plain HTML, CSS and JavaScript. No framework, no build step. Light and dark theme, responsive layout.

## Structure

```
index.html
css/style.css
js/main.js
assets/
  CV_Ahmadul_Karim_Chowdhury.pdf
  images/
robots.txt
sitemap.xml
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

Then visit http://localhost:8000

## Deploy

Hosted on GitHub Pages from the `main` branch, root folder. Every push to `main` redeploys the site.
